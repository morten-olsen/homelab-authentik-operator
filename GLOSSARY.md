# Terms

- **Managed group**: an Authentik group defined by one AuthentikGroup resource, including its complete direct membership.
- **Existing user reference**: an Authentik numeric user ID together with its immutable UUID; it grants membership to an existing human user without provisioning an account.
- **Allowed group**: a namespaced AuthentikGroup reference that can grant access to an application. Any matching allowed group grants access.
- **Application group**: the managed group generated by an application's OIDC chart, independently of additional allowed groups.
- **Access binding**: an Authentik application policy/group/user binding evaluated during a new authorization attempt.
